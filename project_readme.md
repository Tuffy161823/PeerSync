# ⚡ PeerSync

**Campus Peer Study Group & Exam Prep Circle Finder**

PeerSync is a modern, premium web interface designed to connect university students with peer study groups and exam prep circles. This project was developed as a **CA2 Evaluation Project** for the **CSE326 - Internet Programming** course. 

Designed with a sleek, "Notion-meets-Apple" aesthetic, this project demonstrates advanced web design principles, responsive layouts, and interactive UI states—built **entirely without JavaScript or external CSS frameworks**.

---

## 🎯 Project Objective

Students preparing for difficult subjects often struggle to find disciplined peer study partners. PeerSync solves this by providing a centralized directory where students can find, filter, and join study circles based on **Subject Code**, **Target Exam**, and **Study Pace**. 

## ✨ Key Features

* **Breathtaking UI/UX:** Features a premium design with frosted glass navigation (`backdrop-filter`), soft drop shadows, and subtle CSS animations.
* **100% Pure HTML & CSS:** No JavaScript, no Tailwind, no Bootstrap. Demonstrates a deep understanding of core web technologies.
* **Flashcard-Style Directory:** Study groups are displayed as interactive, hover-responsive flashcards.
* **CSS-Only Interactivity:** Uses advanced CSS techniques (like the hidden radio-button hack) to create functional-looking filter chips and layout toggles without JS.
* **Responsive Layout:** Built using modern CSS Flexbox and Grid, ensuring the application looks perfect on desktops, tablets, and mobile devices.
* **Bento Grid Design:** Showcases features on the home page using an asymmetrical, modern bento-box grid architecture.

## 🚀 How to Run Locally

Because this project uses vanilla HTML and CSS, there are no dependencies, build steps, or servers required to run it locally.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/peersync.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd peersync
   ```
3. **Open the application:**
   Simply double-click `index.html` to open it in your default web browser.
